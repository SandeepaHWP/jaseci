- **Fix: `in` and `not in` narrow against a tuple or list of literals**: inside `if x in ("a", "b")`, and in the `else` of `if x not in ("a", "b")`, `x` is now narrowed to those values, so `x: str | None` is no longer reported as possibly `None` there. Every element must be a literal; a variable or f-string element narrows nothing.
