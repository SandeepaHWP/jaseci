- **Feature: warning for `pages/` files that are not routes**: When some `pages/` files are routes but another still returns `JsxElement`, the dev server and build now name that file and suggest returning `JsxPage` (or `JsxLayout` for a layout). Previously the page was silently left out and its URL returned 404. The warning does not fail the build, since a `pages/` component returning `JsxElement` on purpose is still allowed.
