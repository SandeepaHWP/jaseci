# Weapon models

Drop the five weapon GLBs here, named exactly as below (the renderer maps
`weapon_id` -> filename). Any missing file falls back to the box gun.

| weapon_id | filename       | gun     |
|-----------|----------------|---------|
| 0         | `pistol.glb`   | Pistol  |
| 1         | `rifle.glb`    | Rifle   |
| 2         | `shotgun.glb`  | Shotgun |
| 3         | `smg.glb`      | SMG     |
| 4         | `sniper.glb`   | Sniper  |

## Source

Quaternius "Ultimate Guns Pack" - https://poly.pizza/bundle/Ultimate-Guns-Pack-cpgUfI4t2F

License: **CC0 (public domain)** - no attribution required, commercial use OK.

Pick one variant per slot from the pack (it ships GLB), rename to the table
above. Suggested picks: a Pistol variant, an Assault Rifle, the Shotgun, a
Submachine Gun, a Sniper Rifle.

Keep this file updated if you swap in models from another source, recording
that source's license here (Phase 4.6 / PLAN G2-001).
